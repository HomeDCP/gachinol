# 라운드 3 수정 — 문서 횡단 확정 결정 (조율자 발행)

> EVAL-ROUND-3의 미달 사유에 대한 **단일 결정**. X(라운드1)·Y(라운드2) 결정은 계속 유효하다.
> 이번 라운드는 **수렴 라운드**다: 새 범위 발명 금지, 평가서의 감점 사유·정합성 이슈를 닫는 것만 한다.

## Z1. 커머스 = 단계형 (MVP 링크아웃 → 트리거 시 자체 결제 구축) — build/buy 택일

- **MVP(1단계) = 링크아웃(buy)**: 판매자(이장·어촌계장)의 기존 외부 판매 채널(네이버 스마트스토어 등)로 연결한다. 우리 구현 범위는 **라이브 화면 상품 카드 + 외부 링크 + 클릭 계측**뿐이다(02 §B/§E·08 W2에 이 3건만 등재). 판매·결제·환불은 외부 플랫폼 약관·PG가 담당 → 07의 통신판매중개 의무는 "링크아웃 단계에서는 광고·소개 책임 중심으로 경감, 자체 결제 단계 진입 시 §3-4 전체 발동"으로 2단 표기.
- **2단계 = 자체 결제(build)**: 발동 트리거 = **링크아웃 GMV 월 300만원 이상 3개월 연속** 또는 **링크아웃 이탈로 인한 전환 손실이 계측으로 입증**(클릭→구매 완주율 비교). 이때 PG 계약(분쟁·환불 중재 조항 포함)·에스크로·판매자 약관(보증금/유보금 조항)·통신판매업 신고를 **일괄 착수**(05 §G·07 §6에 2단계 착수 체크리스트로 등재 — 현재 시점 실행 항목 아님을 명시).
- 05의 GMV·수수료 시나리오는 1단계(링크아웃 제휴 수수료 or 0%+계측만)와 2단계(중개 수수료 5~8%)를 구분해 재계산한다.
- **효과**: 05 내부 상충·05↔07 상충 해소, MVP 개발 부담 최소화(피벗 취지 정합), §C③ 클레임 절차는 1단계에서 "외부 플랫폼 절차 안내+판매자 연결"로 경감.

## Z2. 후원·멤버십 = 범위 이월 (택일)

- 후원·멤버십 축은 **웹 피벗·MVP 범위에서 제외**한다(구독자 인증 체계 설계가 선행 필요 — 현재 구독자 앱은 익명). 05 §A-4는 "이월 트랙" 표기로 전환: 착수 트리거 = **WAU 3,000명 이상 + 커머스 2단계 진입 이후 검토**. D11(쉘 내 디지털 재화 비노출)은 이월 후에도 유효한 가드레일로 유지.
- MVP 수익 축 = 커머스(링크아웃)·B2B·광고협찬 **3축**으로 손익 시나리오 재정리.

## Z3. 동시시청 환산 계수 = 01 소유

- 01 §C-6(수요 KPI 궤적)에 **"회당 동시시청 = WAU × 환산 계수"의 계수(가정 명시)**를 추가하고, 04 §E(용량 계획)·05 §A-1(GMV 분해)은 그 계수를 인용해 연쇄 재계산한다. 두 문서의 독자 계수 정의 금지.

## Z4. 지사 담당자 직통 전화 = 06 채널 표에 신설

- 03이 발주한 "지사 담당자 직통 전화"를 06 §A 채널 표에 정식 행으로 신설(대상: 출연자·고령 시청자 인접 문의, SLA·대장 기록·이관 규칙 동일 적용)하고 §B 라우팅 다이어그램에 경로를 추가한다. 05 §B-3 인건비와 부하 정합은 01 §C-7 총부하표 인용으로 처리.
