# 라운드 5 수정 — 문서 횡단 확정 결정 (조율자 발행)

> EVAL-ROUND-5 대응 마감 라운드. X·Y·Z·V 결정 유효. 새 범위 발명 금지.

## U1. 01 §A-4 목표 표기 = 절대값으로 교체

- "네이티브 대비 +20%" 상대 목표는 기준선(네이티브 실측)이 존재하지 않으므로 **절대값 목표로 교체**한다(값은 01이 기존 가정 체계에서 산정, '가정' 표기). A2HS 산출식의 노출 모수(60%/75%)는 산식에 명시.

## U2. 05 운전자금 = 월별 격차 12행 합산으로 재산정

- 현행 "종점값×6" 방식 폐기 → **월별 순현금유출 12행 합산**으로 재산정하고, 누적 상한(현 8,000만원 가정)은 재산정값 + 여유 버퍼로 **재설정**한다('가정' 유지, 산출 표 포함). §G에 외부 조달원 조사(지자체 공모·지역 미디어 지원사업 목록화, 담당·기한) 항목 신설. 헬프데스크 도구비(06)·지역 매니저 인건비(06 §B 스케일 규칙)는 05 §B-3 "트리거 발동 시 증분" 행으로 편입(D-18과 동일 패턴).

## U3. 선후 관계 확정 — 디자인 토큰 게이트 → 패널 R1

- `packages/ui` 토큰 승격(W1 차단 게이트)은 **패널 R1 이전 완료**가 순서다. 03·08은 이 선후를 명시해 모순 제거.

## U4. 라이브 폭주 시 모더레이션 분담 = 센터장 + 당번 지사 담당자

- 06의 폭주 시 분담을 평가자 지적대로 교체(센터 운영자는 04 역할 배치상 방송 제어 점유 — 06·04 역할표 정합).

## U5. 대장 확장 — "인용 갱신" 유형 행 신설 (PMO)

- PIVOT-PLAN §6에 **단일 원천 값 6개**(01 §C-5 방송 슬롯·§C-6 WAU/계수·§C-7 총부하, 05 §B-3 인건비·§C 트리거, 02 §C TTFF/성능 예산)의 **전 인용처 목록 행**을 신설하고, 이후 라운드마다 원천 값 변경 시 인용처 전건 대조를 의무화한다.

## U6. 07 잔여 3건

- §3-11 접근성 판정 착수 시점 = **W0 동시**로 앞당김. §6 "즉시" 표기는 "계획 승인 시점 기준"으로 재정의. §4 카카오 행에 국내 제3자 제공/처리위탁 판정 액션 추가.
