# 라운드 8 수정 — 문서 횡단 확정 결정 (조율자 발행)

> EVAL-ROUND-8 대응. 전 라운드 결정 유효. **전파 마감 라운드** — 원천 값 신값의 인용처 전파와 대장 정합이 전부다.

## Q1. 조율자 검증 원칙 (자기 교정 — 재발 방지 규칙)

- 라운드 7에서 조율자가 PIVOT-PLAN §6-5에 "05·06 재계산 확인"을 **grep 실행 없이 선언**했고, 이는 허위 검증이었다(EVAL-ROUND-8 적발: 05·06에 총부하 구값 잔존). **재발 방지 규칙**: 대장·인용 대조의 "확인했다" 서술은 **실행한 grep 결과가 있는 경우에만** 기재한다. 원천 값이 변경된 라운드는 조율자가 6-5 대조를 실제 실행하고 결과(일치/불일치 목록)를 기록한다. 이 규칙을 §6-5 서두에 명문화한다(PMO 수행).

## Q3. 대장 정합 (PMO — 파일 수정 라운드 종료 후)

- PIVOT-PLAN §6에 07 라운드 6·7 발주(EVAL-ROUND-8 ④ 명시분)를 등재하고 실제 수신 여부를 grep으로 판정해 정직 기재(미수신이면 미수신으로).
- §6-5의 "라운드 7 갱신" 문단을 Q1 규칙에 따라 재작성: 이번 라운드 전파 완료 후 **실제 grep 결과**로 대조 문단을 교체. §6 헤더 총계 갱신.
