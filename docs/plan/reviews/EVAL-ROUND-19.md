**앵커 충족 근거**

- **재사용/폐기 판정이 파일 단위로 구체적이고, 실측이 전건 재현된다.** 02 §B 판정표는 `packages/shared`(재사용

  (프레임워크 3 + shared)을 분모 밖으로 **근거를 대며** 제외한 것은 인벤토리 규율의 모범이다.

### 영역 2. 서비스 성립성 — **9.5**

**주 근거 문서**: 01-product-strategy.md §A, 02-web-architecture.md

**앵커 충족 근거**

- **논증 대상이 정직하게 좁혀져 있다.** 01 §A-1은 성립을 논증하는 루프를 1~8행(촬영→자동 트랜스코딩·프리뷰→
  기자 승인→송출→시청)으로 한정하고, 9행(`auto_edit`)을 **루프 밖 T-AI-2**로 분리한다. 리포 실측 결과
  `auto_edit`는 `packages/shared/src/job/job.ts`의 상수와 media-worker 주석뿐 구현이 없고 ai-worker는
  `stub` 기본값이라, 이 분리는 사실 관계에 정확히 부합한다. "AI가 편집해 방송국이 송출"이라는 제품 최종
  가치가 **아직 없다**고 §A-5 리스크 첫 행에 명시하고 단정 마케팅 표현을 금지한 것은 근거 없는 낙관의 반대다.

  2차(<20%, 3단 조치 전건 + 프레임 자체를 B-6 리스크로 등재)로 무조치 구간을 메웠고, 판정자(기획 PM)와
  시점(MVP+10주 / +6개월)이 있다.
- **단일 경로 의존이 해소돼 있다.** B-3(B2B 컨택)이 B-4(객원 인력 개인 네트워크)에만 의존하던 구조를 —
  B-4 미성사(MVP+8주 위촉 0건) 트리거 시 2순위 지자체 미디어 담당 부서 / 3순위 지역언론 공모·협력 프로그램으로
  전환하도록 열었고, B-4 자체도 2순위(대학 미디어학과)·3순위(지자체 마을미디어 활동가 풀)를 확보했으며,
  **확산 단계(6개월 4명)의 레퍼럴 단일 경로 비대칭**까지 별도 리스크 행으로 신설해 2·3순위 상시 병행을
  규정했다(6개월 누적 <2명 시 KPI 파일럿 수준 하향 + 컨택 경로 영구 전환, 판정 기획(PM)).
- **논지 성립 조건이 게이트다.** "판매가 곧 흡수"라는 B-3 논지는 크레딧 표기가 없으면 성립하지 않으므로,
  05 §A-2 계약서 표준안에 출처 크레딧 표기 의무를 반영하고 **미반영 시 첫 B2B 시연 자체를 보류**하는 게이트를
  §B-7에 걸었다(05 grep 수신 확인).
- **경쟁 대응이 있다.** 레거시의 포맷 모방 리스크에 대해 복제 난이도가 높은 3자산(개인 브랜드·물리 거점·
  기존 카톡 친구 기반)을 해자 논리로 제시하고 인지 시점을 트리거로 삼았다.
- **모수의 신뢰도를 정직 기재한다.** 애월읍 인구 36,233명이 2019년 값임을 밝히고 "이 수치를 목표 산정 근거로
  그대로 쓰지 않는다"고 못박은 뒤 실사를 §B-7 항목(담당 기획 PM, 기한 MVP 착수 전)으로 등재했고, 제주시 목표는
  실사 완료까지 "별도 산정" 미확정 상태로 남겼다.
- **대리 등록 법적 리스크가 닫혀 있다.** QR 부스·자녀 경유 등록이 제3자에 의한 광고성 정보 수신동의라는
  구조적 문제를 B-6 리스크로 신설하고, 증빙 필드 3종(동의 일시·등록 방식[본인/대리]·수신거부 안내 고지)을
  §B-7에 등재하며, **07 §3-17 판정 회신 전까지 대리 등록분 광고성 메시지 발송을 보류**한다.

**잔여 관찰(감점 아님)**

- "1개월 100명 → 3개월 1,000명" 구간의 갭이 정직하게 노출돼 있다: 부스 산식으로 약 500명(목표 900명의 56%)만
  설명되고 **잔여 400명은 "검증되지 않은 낙관 가정(초기 등록자의 자연 확산)"임을 명시**한 뒤, 3개월 시점
  부스 기여분/자연 확산분 분리 집계와 목표 자체의 성립 여부 재판정을 트리거로 걸었다. 이는 "숨겨진 낙관"이
  아니라 "노출된 낙관 + 재판정 규칙"이라 RUBRIC상 감점 대상이 아니다.

**9.5 유지 조건**

1. §B-7 인구 실사 완료 시 B-2 목표표(제주시)·각주 5·6·B-5 KPI·01 §C-6 WAU 궤적·그 파생인 04 §E M12 행과
   R11 임계값(150명)을 **같은 라운드에 전건 재계산**한다(04 §E가 이미 "01 §C-6 갱신 +2주" 갱신 책임을 명시하고
   있으므로, 01 쪽에도 동일 연쇄 목록을 §B-7 항목에 병기하면 대칭이 완성된다).
2. 07 §3-18(재설문 목적 외 이용) 판정이 회신되면 §B-5 측정 방법·§B-7 등록 폼 문항을 회신 결과로 갱신하고,
   보류 단서를 해제 또는 유지로 확정한다.

### 영역 5. 콘텐츠 확보 용이성 — **9.5**

**주 근거 문서**: 01-product-strategy.md §C, 03-accessibility-ux.md §C

**앵커 충족 근거**

- **품질 하한이 코드 계약으로 강제된다.** `Content{title,category,scenes[]}`·`Scene{order,caption(필수)…}`는
  UI 가이드가 아니라 서버 타입 계약이므로 "제목 없이·자막 없이" 업로드가 불가능하고, 웹 전환 후에도 무변경이라
  하한이 유지된다 — 검증 가능한 메커니즘 기반 주장이다.
- **진입장벽이 두 축으로 낮아진다.** ①간단 모드(03 §C-4: 자막 단계를 촬영자에게서 걷어내 지사 담당자 사후
  입력) ②주민 임시 업로드 링크(03 §C-5: 72시간·5건·500MB·IP 시간당 10회·검수 게이트 필수). 두 축 모두
  **STT 비의존으로 재설계**됐다 — ai-worker가 스텁이라서가 아니라 "검수 없는 자동 자막을 게시하지 않는다"는
  원칙으로 근거를 세운 점이 견고하다.
- **캘린더가 MVP 실제와 목표 상태로 분리됐다.** MVP 격일 로테이션표(애월 3건·제주시 2건)가 C-6 KPI 출발점과
  정합하고, 목표 상태(12지사)는 별도 표로 분리해 "매일 갱신 날씨예보"가 목표 상태 전용임을 명시한다.
  라이브커머스 **방송 슬롯**(촬영이 아니라 방송)이 캘린더 어디에도 없던 공백을 요일·주체·빈도 램프
  (M3 월2회 → M6 월4회)로 신설하고, 이 절이 04 §A/§E·05 §A-1/§B-1이 인용하는 **방송시간 모수의 단일 원천**임을
  선언했다(04·05 인용값 재현 일치).
- **주 3건→5건 증가분의 경로가 명시되고, 실패 시 자동 하향 규칙이 있다.** C-5-1 전환표가 지사별 추가 요일·
  소재 카테고리·확보 경로·담당을 적었고, 흡수 경로 ②(B-4 객원)·③(W2 주민 제보) 중 **하나만 미충족 시 주 4건,
  둘 다 미충족 시 주 3건 유지**로 자동 하향하는 규칙(판정: 지사 담당자+기획(PM), 시점: 첫 촬영 재개 +10주)을
  뒀다 — 목표만 걸고 방치하지 않는다.
- **공급 능력의 상한이 계산돼 있고 초과가 인정된다.** C-7 총부하표는 9개 업무를 주당 시간으로 합산해
  W2 가동 전/후 × M3~M5 / M6 이후 4개 구간으로 나누고, **M6 이후 당번 주 최대 약 37~47시간이 40시간을 구조적으로
  상시 초과**함을 인정한 뒤 M5 말 센터장 택일((a) 증원 / (b) 방송 빈도 하향)을 게이트로 걸었다. 양 선택지 모두
  갱신 대상 문서 목록·담당·기한이 있고, (a)의 인건비 증분(+150만원/월)이 05 §B-3①에 계상돼 **재무 영향이 산정된
  선택지끼리 비교**하게 만들었다. 이 값의 인용처 5곳과 전파 책임자(기획 PM)까지 명시돼 있으며, 본 평가의
  grep 결과 5곳 전건 신값(37~47h) 동기화가 확인됐다.
- **수요 측 KPI가 신설돼 "올리지만 아무도 안 봄"을 감지한다.** WAU 궤적·회당 동시시청 계수(01 단일 소유)·
  완시청률·7일 조회수·카테고리별 조회 편차. 계측 파이프라인(02 §E 16번, W1) 완성 전에는 **대체 측정 원천**
  (카톡 채널 통계, `GET /v1/feed/:id/playback` 액세스 로그 집계)을 명시하고, 완시청률은 **"측정 불가 상태를
  그대로 인정"**하며 포맷 교체 트리거에서 제외했다 — 없는 측정을 있는 척하지 않는다.
- **가정치의 실측 검증 경로가 있다.** 간단 모드 채택률 40%는 02 §E 16번 모드 선택 이벤트로 W1부터 실측하고
  ±15%p 이탈 시 총부하 행과 4개 합계 행을 재계산한다(담당 기획(PM), 시점 W1 완료 +4주).
- **카테고리 커버리지 100%가 절차로 보장된다.** MVP 캘린더에 `politics_talk`가 지사 편성으로 없어 특정 월 0건이
  가능하다는 점을 인정하고, 캘린더가 아니라 **월간 편성표 확정 시 센터 편성 담당의 필수 확인 절차**를 실제
  보장 장치로 지목한 뒤 미이행 트리거(<100% → 다음 달 강제 배정, 2개월 연속 → 편성회의 자동 상정)를 붙였다.

**잔여 관찰(감점 아님)**

- 주민 제보 비중 10% KPI는 W2 가동 이후 6개월 기준이며 1차(3개월 <5% → 인센티브 강화)·2차(6개월 <10% →
  형태 재설계 또는 목표 하향) 2단 판정이 있다. 인센티브 운영안 자체는 §C-8 항목(담당 센터 편성 담당,
  기한 W2 착수 전)으로 등재돼 있고 예산은 05 §B-1에 반영됐다(grep 수신 확인).

**9.5 유지 조건**

1. 01 §C-8이 소유한 카테고리별 Scene 순서 원안 6종 중 미확정 4종(`news`·`politics_talk`·`culture`·`emergency`)이
   확정되면 03 §C-2-2 UI에 즉시 반영하고, 반영 여부를 §C-8 체크리스트에서 grep으로 확인한다(현재 2종만 반영).
2. W1 간단 모드 채택률 실측 결과가 40%에서 ±15%p 이상 벗어나면 C-7 해당 행과 4개 합계 행뿐 아니라
   **인용처 5곳(05 §B-3①·정합성 한계 문단·§G, 06 §A·§F)까지 같은 라운드에 전파**한다(37~47h 전파와 동일 절차).

### 영역 6. 고령층 사용성 — **9.6**

**주 근거 문서**: 03-accessibility-ux.md

**앵커 충족 근거**

- **기준선이 코드 실측으로 잡혀 있다.** 현재 본문 16px·캡션 13px·제목 20px·터치 타깃 최소 크기 미정의를
  `apps/subscriber/src/ui/theme.ts` 실측으로 제시하고(리포에서 3앱 로컬 `theme.ts` 실재 확인),
  "13px 캡션·8px 여백 칩은 60~80대에게 사실상 읽을 수 없거나 누르기 어려운 수준"이라고 정면으로 기재한다.
- **목표 수치가 확정되고 실현 경로가 있다.** 본문 18px+/캡션 16px+/제목 22px+/큰 자막 22~24px(정본 명시)/
  타깃 44×44pt+·인접 여백 8px+. react-native-web이 숫자를 `px`로 직역해 `rem`이 RN 표준이 아니라는 **기술적
  제약을 인정**하고, `packages/ui`가 웹 빌드 한정 CSS 커스텀 프로퍼티를 노출하고 네이티브는 `Platform.select`로
  분기하는 실현 경로 + 일정(W1 착수 전 토큰 승격, W2까지 3앱 전환)을 제시했다.
- **WCAG 2.2 AA를 바닥선으로 삼고 국내 기준을 매핑했다.** 8개 SC별로 AA 요구치·자체 목표(본문 대비 7:1 등)·
  적용 범위·KWCAG 2.2 대응을 표로 정리하고, **KWCAG 미대응 항목(2.5.8 타깃 크기)과 국내 고유 요구(자막·수어)의
  차이를 스스로 지적**하며 법정 적용 대상 여부 판정을 07 §3-11에 위임했다.
- **검증 설계가 판정 가능하다.** 3회차 패널(R1 토큰 확정 후 조기 관측 / R2 런칭 직전 / R3 런칭+4주),
  과업 5종(FAQ 열람 과업 포함), 성공 기준 6개, **표본 크기별 실패 허용치 판정식 ⌊N×0.1⌋과 경계값 처리
  (±1명 범위는 24명으로 확대 후 재판정)**, SUS 한국어 10문항 고정(회차 간 비교 가능성 확보), "치명적 접근성
  결함"의 정의(ⓐ·ⓑ)·판정 주체(모더레이터+FE 리드 24시간 내 합의)·기록 양식까지 확정돼 있다.
- **검증 설계의 구조적 한계를 스스로 폭로하고 별도 트랙을 만들었다.** 모집 조건("스마트폰 보유·카톡 사용 경험")이
  **이 서비스의 최대 접근성 장벽 집단(70대 이상 보유율 36.3%·앱 설치 실패 60%)을 원천 배제**한다는 사실을
  명시하고, 패널 통과가 증명하는 것은 "이미 쓰는 사람은 쓸 수 있다"뿐임을 못박은 뒤 자녀 경유 등록·마을회관
  공용 기기 두 접점에 대한 **대면 정성 관찰 1회**를 B-3 온보딩 방문에 끼워 넣었다. 그래도 닿지 않는 인구는
  **"이 계획에서 검증하지 않는다 — 검증 수단이 없다는 것이 이유이며 이는 축소가 아니라 명시적 판정"**이라고
  기록했다. 이는 심사역 관점에서 가장 신뢰를 주는 종류의 서술이다.
- **사후 재작업 비용에 상한이 있다.** R1이 사전 검증이 아니라 이미 배포된 토큰의 사후 관측임을 인정한 뒤,
  미달 시 **경미(다음 정기 배포 편입) / 중대(즉시 토큰 재조정 + 소급)** 2단 분리와 **지연 상한 2주 초과 시
  08 §D 이관 → 기획(PM)의 범위 축소 판정**을 뒀다(07 §3-11 KWCAG 소급 규칙과 대칭).
- **공급자 측 검증이 신설돼 있다.** B-4(기자·주민 사용성 검증)가 대상 4~5명·2회차(W2 DoD 직전 / 첫 촬영 재개
  +4주)·과업 4종·성공 기준을 갖추고, 소표본(N=4~5)에서 ⌊N×0.1⌋=0이 되는 문제를 인지해 "1명 실패 시 즉시 원인
  조사하되 단독으로 게이트 불통과를 확정하지 않고 2차 회차로 재관측"으로 처리했으며, 과업 3의 100% 기준이
  KPI 요약(≥95%)보다 **엄격한 이유(소표본)**까지 명시했다.

### 영역 8. CS 구축 — **9.5**

- **부재·이직 대응이 있다.** 지사 담당자 백업 = 인접 지사 담당자, 센터 운영자 백업 = 센터장으로 사전 지정하고
  인수인계 체크리스트를 문서화(담당·기한 명시).
- **서면 채널의 미채택 판정이 근거를 갖는다.** 웹 문의 폼을 두지 않는 이유 3가지(익명 원칙상 신원 확인 수단
  부재 → 스팸 취약 / 접수 창구 이원화로 "대장 없는 CS 금지" 예외 증가 / 이메일이 첨부·회신에 더 적합)를
  제시해 **"미검토의 결과가 아니라 결정의 결과"**임을 밝혔다.
- **품질 신호가 있다.** 처리 속도 지표 일색에서 벗어나 **1차 해결률(전화 채널 재문의 없는 종결 비율 ≥70%,
  잠정 — 첫 3개월 실측 후 재설정)**을 신설하고 측정 방법(통화 종료 시 1클릭 기록 + 7일 내 동일 발신번호
  재문의 대사)까지 지정했다.
- **실행 체크리스트 22개 전건에 담당·기한이 있다**(실측 확인).

**잔여 관찰(감점 아님)**

- 다채널 통합 인박스 지원 여부는 카카오 도구의 외부 제약이라 W1 실측 검증 항목이며, 미지원 시 대체안 3종과
  발동 조건(결정권자 센터장, 비용 월 ~$50)이 준비돼 있다.

**9.5 유지 조건**

1. §B "지사 확장 시 창구 스케일 규칙"의 인력 부하 산식(채널 수 × 예상 문의량 × 이관 소요 vs 센터 운영자 근무
   예산)은 W1 중 산출 예정이다 — 산출 결과가 나오면 §A "코어타임과 05 §B-3의 산술 정합" 문단에 합산해
   **전화·게시·이관 3항목의 통합 부하율**로 갱신한다(현재는 통화+게시 2항목만 합산돼 있다).
2. 1차 해결률 첫 3개월 실측 후 재설정 시, 재설정 값이 §D 월간 VOC 리포트 고정 항목과 §E 리스크 트리거에도
   반영되는지 같은 라운드에 확인한다.

### 영역 9. 소통창구 관리 — **9.6**

**주 근거 문서**: 06-cs-voc.md §B

**앵커 충족 근거**

- **대원칙이 사용자 부담을 제거한다.** "시청자가 라우팅을 고민하게 하지 않는다 — 어느 창구로 들어와도 접수한
  쪽이 대장에 기록하고 내부에서 이관한다"는 원칙이 다이어그램·이관 규칙·회신 책임으로 일관되게 구현됐다.
- **라우팅 다이어그램이 실제 창구 전건을 덮는다.** 시청자·구매자(지사 카톡 / 센터 카톡·전화 / 지사 담당자 직통 /
  **대표 이메일** / 라이브 채팅) + 출연자·판매자(직통 1차 + 대표번호 2차) + **광고주·협찬사**(사업개발 담당
  1차) + 내부(관제 앱 = 공식 창구, 카톡 개인 지시 금지) 4개 축으로 분리되고, 각 노드마다 다음 홉과 대장 기록
  책임이 표기돼 있다. 광고주 창구는 B2B(1차 = 센터장)와 접수 주체를 **의도적으로 다르게** 두고 그 근거
  (콘텐츠 구매 문의 vs 협찬 영업 문의, 05 §B-3 담당 배분 준수)를 명시했다.
- **SLA 시계가 이관으로 리셋되지 않는다.** "이관은 접수 후 2시간 이내, 첫 응답 SLA 시계는 **접수 시각 기준
  유지**, 접수 채널로 회신하는 책임은 접수자에게 남는다(시청자가 두 번 설명하지 않게)"는 세 규칙이 다이어그램
  각 경로에 반복 명시돼 있다. 채널별 "접수 시각"의 정의(카톡=메시지 수신 / 전화=최초 착신(콜백 완료 아님) /
  이메일=원본 수신 헤더(자동전달 수신 아님))까지 고정해 측정 모호성을 제거했다.
- **원칙이 선언에 그치지 않고 감시 수단을 갖는다.** "카톡 개인 지시 금지"가 휴무 이력 있는 조직에서 자연
  붕괴하기 쉽다는 점을 인정하고, **"관제 앱 수정요청 건수 대 실제 반려·재작업 건수 대사"**를 월간 VOC 리포트
  고정 항목으로 두어 "관제 앱 로그로 설명되지 않는 재작업 = 카톡 개인 지시의 방증"으로 삼고, 월 3건 이상 시
  편성회의 자동 상정 트리거를 붙였다. 채널별 수신 건수 대 대장 등재 건수 **대사(reconciliation)**와 괴리율
  >10% 원인 조사도 같은 성격의 실효 장치다.
- **확장 시 붕괴 지점이 사전 검증된다.** "신규 도구 최소화" 원칙이 12지사에서도 성립하려면 카카오 채널 관리자
  도구가 13채널 통합 감시를 지원해야 한다는 전제를 **가정으로 남기지 않고 W1 중 실측 검증** 항목으로 만들고,
  미지원 시 대체안 3종과 조기 도입 판정(결정권자 센터장, 독립 트리거, 두 트리거 중 먼저 도달하는 쪽)을 뒀다.
  나아가 "지사 5개 초과"까지 센터 운영자 1인이 이관 허브를 감당 가능한지가 산정된 적 없다는 공백을 지적하고
  **채널 수 × 문의량 × 이관 소요 산식을 W1 중 산출**해 초과 시 지역 매니저 신설 트리거를 앞당기도록 했다.
- **개인 회선 리스크가 정책화됐다.** 지사 담당자 직통이 개인 소지 회선이라는 점에서 ①업무 사용 서면 동의
  ②착신전환/세컨드 번호 권장(개인 번호 직노출 금지) ③번호 승계 규칙(리플렛 재인쇄 불요 원칙 포함) ④근무시간
  외 수신 규칙 4개 항을 두고, 처리방침 반영 요건을 07 §5-4에 위임했다(양방향 grep 수신 확인).
- **비-클레임 SLA가 분리돼 있다.** 출연자·판매자의 일정 조율·정산 확인 등 클레임이 아닌 문의에 영업일 1일 내
  1차 회신(해결이 아니라 접수 확인 + 처리 일정 안내)을 두어, 클레임 SLA와 혼용되지 않게 했다. 동일 회선을
  겸용하되 **발신 목적에 따라 SLA 트랙만 분기(회선·대장은 하나)**라는 처리도 명확하다.
- **폭주 시 역할 분담이 04와 정합한다.** 프롬프터 수집 50건 초과 시 등재 기한을 익영업일로 연장하되 미등재 0을
  유지하고, 모더레이션은 **센터장 + 당번 지사 담당자**가 분담해 센터 운영자가 상태 전이 API에 전념하게 한다 —
  아나announcer는 04 §C 역할 배치상 이미 방송 진행·프롬프터 인지·오보 정정 스크립트 낭독을 맡고 있어 추가
  부담이 불가하다는 **04와의 정합 근거**를 명시했다.

**잔여 관찰(감점 아님)**

- 반자동 게시 담당의 실체(지사 콘텐츠=지사 담당자 / 센터·대행=센터 운영자)와 건별 공수(≈10분/건)를 06이
  정의하고 01 §C-7에 입력값으로 제공하는 구조가 명확해, 02 §D-T6·04 §D가 호출하던 "반자동 게시 담당자"의
  오너 부재가 해소됐다.

**9.5 유지 조건**

1. W1 중 산출되는 "채널 수 × 문의량 × 이관 소요" 결과로 지역 매니저 신설 트리거의 **구체 임계치**를 확정하고
   (현재 "산출 결과로 확정" 상태), 확정 값을 §A 산술 정합 문단·05 §B-3 지역 매니저 증분 행과 동시 갱신한다.
2. 다채널 통합 감시 실측 결과(지원/미지원)를 §B에 기록하고, 미지원 판정 시 대체안 채택 결과를 §F 12번
   체크리스트에 완료 표기와 함께 남긴다.

### 영역 10. 클레임 해결 — **9.6**

**주 근거 문서**: 06-cs-voc.md §C·§E, 07-legal-license.md §5

**앵커 충족 근거**

- **9개 유형이 SLA·절차·에스컬레이션 3열로 정리돼 있다.** ①권리침해 삭제(초상권·개인정보·명예훼손) ②방송 내용
  오류 ③커머스 ④기술 장애 ⑤채팅·댓글 신고 ⑥제3자 저작권·플랫폼 스트라이크 ⑦라이브 실시간 오보 ⑧개인정보
  유출·침해사고 제보 ⑨광고·협찬 계약 이행 분쟁. 각 유형의 1차 조치 SLA가 성격에 맞게 차등화돼 있다
  (24시간 임시 비공개 / 영업일 1일 / 방송 중 즉시 / 접수 즉시 통보).
- **다채널 확산 구조에서 "삭제가 실제로 삭제인가"를 끝까지 추적한다.** §C①의 외부 채널 전파 목록이
  **YouTube(API) · Facebook 페이지(라이브 동시송출 아카이브) · 카톡 채널(수동) · 공개 렌디션 버킷+CF 캐시 퍼지
  (D-T8 가동 후) · B2B 판매분(방영 중단·회수 협조 공문)** 5종을 모두 덮고, 각각 담당·완료 확인·대장 기록까지
  규정한다. Facebook 행에는 **"04 §H-1 R4 게이트로 YouTube 단독 송출됐던 방송은 처리 대상 자동 제외"**라는
  조건부 단서까지 붙어 실제 운영 분기를 반영한다.
- **KPI가 실효를 측정한다.** 삭제 요청 24h 준수율 100%를 **1단계(서명 URL — 캐시 퍼지 측정 범위 밖)**와
  **2단계(D-T8 후 — 공개 버킷 삭제 + CF 퍼지 API 성공 여부를 대장 컬럼으로 추가, 둘 중 하나라도 미완료면 위반)**로
  분리했다. "만료 없는 공개 URL이라 퍼지 누락이 곧 24h SLA의 실효성을 훼손한다"는 인과가 명시적이며,
  02 §D-T8이 삭제·퍼지를 **"공개 복사와 짝을 이루는 필수 단계, 순서 분리 금지"**로 못박아 양방향으로 닫혀 있다.
- **법정 근거와 운영 절차의 소유권이 분리돼 있다.** 07 §5-1이 법정 요건(지체 없는 조치·양측 통지·30일
  임시조치·공시·약관 명시 의무)을 공급하고 06 §C①이 운영 절차를 소유하며, 06의 24시간이 법정 "지체 없이"보다
  엄격한 자체 기준임을 양쪽이 동일하게 기재한다. §C⑤ 명예훼손의 근거를 07 §3-8(불법촬영물 전용)에서
  07 §5-1(정보통신망법 제44조의2)로 정정한 이력도 근거 정확성을 높인다.
- **접수 시각·경로의 사각지대가 닫혀 있다.** 야간·주말·방송 중 5개 경로(①카톡 상시 푸시 ②당번의 즉시 센터장
  에스컬레이션 ③센터장의 상시 비공개 권한 사전 부여 ④방송 중 아나운서 구두 인지 ⑤**이메일 키워드 자동전달·
  푸시 + 1일 2회 정시 확인**)가 명시되고, 이메일 SLA 셀에 **"24h/즉시 시계는 접수 시각부터 즉시 기동 —
  접수 회신 SLA는 발신자 확인용일 뿐 내부 1차 조치 기동을 늦추는 근거가 아니다"**라는 구분이 있다.
- **3선(법무) 공백이 정직하게 관리된다.** "계약 체결 전까지는 3선 에스컬레이션이 실행 불가"임을 인정하고,
  잠정 대행의 **기본값("의심스러우면 임시 비공개")**과 **상한(법적 판단이 필요한 복원 결정은 대행 범위 밖)**,
  **종료 규칙(첫 촬영 재개 예정일 도달 시 촬영 보류 게이트 발동)**을 뒀다. 대행이 무기한이 되지 않도록 만든
  구조가 특히 견고하다.
- **커머스 클레임이 단계별로 정확하다.** 1단계(링크아웃)는 외부 플랫폼 절차 안내 + 판매자 연결로 경감되고
  KPI도 "안내·연결 완료율 ≥95%"만 요구하며 **"1단계에는 PG·정산 리포트가 없어 GMV 대비 분쟁률은 측정 불가능
  하므로 KPI로 요구하지 않는다"**고 명시했다 — 측정 불가능한 KPI를 걸지 않는 규율이다. 2단계 진입 시 청약철회
  7일·판매자 3영업일·PG 중재 등 전체 절차가 발동한다.
- **리스크 테이블이 실패 모드를 덮는다.** 지사 CS 방치(48h 감사) / 외부 채널 잔존(삭제 체크리스트 = 대장 필수
  컬럼, 전 채널 확인 전 종결 불가) / 이메일 24h 이탈(월간 대사에서 1건 이상 발견 시) / 라이브 폭주(준비 발동과
  대응 발동 분리) / 법무 미계약(촬영 보류 게이트) / 2단계 환불 강제 수단 부재 — 전건에 담당·트리거가 있다.

**잔여 관찰(감점 아님)**

- ⑧개인정보 유출·침해사고는 06(접수·초기 등재·최초 에스컬레이션)과 07 §5-7(법정 요건·절차 골격)의 소유권
  경계가 양쪽에 대칭 기재돼 있고, 최종 판단권을 센터장이 아니라 **PO+외부 법률자문 이중 확인**으로 둔 근거
  ("법정 통지·신고는 되돌릴 수 없다")도 명시적이다.
