# 라운드 10 수정 — 문서 횡단 확정 결정 (조율자 발행)

> EVAL-ROUND-10 대응. 전 라운드 결정 유효.

## N1. 기술 런칭 / 대외 런칭 분리 — 시드 콘텐츠 게이트 (J-1 해소, 01·08 소유)

- **결정**: W1의 DoD는 **기술 런칭**(TTFF·OG·인앱 검증 등 기술 지표)으로 유지한다. **대외 런칭(카톡 채널 공지·홍보 개시)은 별도 게이트**로 분리: **시드 콘텐츠 6건(가정 — 지사당 2건 + 센터 제작 2건: 소개·날씨 파일럿) 확보 시** 개시. 시드 콘텐츠의 공급원 = 첫 촬영 재개(07 법무 게이트 통과) 후 초기 촬영분 + 센터 자체 제작분. **미달 시 대외 런칭 보류**(기술 런칭 상태로 대기 — 소프트 런칭). 01 §A에 "전환 기간(W0~W2) 중 서비스 상태" 소절 신설(시점별 시청자가 보는 것·콘텐츠 출처·지사 온보딩 시점), 08 §A 마일스톤 매핑에 "대외 런칭" 앵커 추가.

## N2. 01 잔여 — 레거시 KPI 2단 조치·기준점 재정박

- §B-5: 목표(≥30%)와 조치 트리거(<20%) 사이 무조치 구간을 2단으로 — **20~30% = 원인 분해 + 부스·소재 조정(경조치), <20% = 기존 3단 조치**. §C-6: "MVP 1개월 주 3건"의 기준점을 **"첫 촬영 재개(W2 DoD 직전) 시점 기준 M1"**으로 재정박, §B-3 라이브러리 축적 시점 연쇄 갱신.

## N3. 05 — W축 지연 매출 민감도

- §B-3③에 "W축 지연 시 현금 민감도" 신설: W1/W2가 각 1개월 지연되면 매출 램프 전체가 1개월 우측 이동(비용은 유지)한다는 가정으로 누적·런웨이 영향 1문단(수치 포함).

## N4. 03 — R1 미달 소급 규칙

- 리스크 1에 07 §3-11과 대칭인 **소급 재작업 2단 분리**(경미: 다음 배포에 편입 / 중대: 즉시 재조정) + **지연 상한 2주** 부여.

## N5. 04 — SLO#2 소표본 판정 규칙

- SLO#2(방송 시작 성공률 ≥98%)는 월 모수(≈12회)가 작아 1회 실패=92%로 즉시 미달이 되는 구조 — **판정을 분기 누적 모수(≈36회) 기준**으로 전환하고, 즉시 대응은 "**연속 2회 시작 실패 시 원인 분석·게이트 재점검**" 이벤트 규칙으로 분리. 첫 분기 실측 후 목표 재확정 트리거 부여.

## N6. 06 — 이메일 채널 배선 마감

- 대표 이메일 접수분에 **§C① 24h 시계 즉시 기동** 명시 + **야간·주말 확인 경로**(주말 당번이 1일 2회 확인 등). §B 라우팅 다이어그램에 이메일 노드 추가, §C⑧ 접수 채널 열거 교정, §C① 접수 경로에 이메일 편입, **채널별 접수 시각 기록 규칙**(24h 준수율 KPI 측정 기준) 명시.

## N7. 07 — 익명 이용자 약관 동의

- 무회원 익명 이용자의 이용약관 편입 방법 판정 신설: **웹 고지(푸터 상시 링크) + 행위 시점 동의**(라이브 채팅 닉네임 입력 시 동의 체크, 주민 업로드 링크 사용 시 동의 화면)를 기본안으로, 순수 시청은 고지 기반(브라우즈랩의 한계 명시·법률자문 확인 항목). §6 라운드 9 발주 행들을 grep으로 수신 완료 갱신.

## N8. 02 — 재사용률에 쉘·PWA 산출물 계상

- §B 재사용률 분모에 쉘·PWA 신규 산출물(TWA 설정·WKWebView 래퍼·APNs 브릿지·manifest·서비스워커)을 계상해 재산정(제외 근거의 순환 해소). 08 §A W1 DoD에 N1의 대외 런칭 게이트 반영.
