# 라운드 14 수정 — 문서 횡단 확정 결정 (조율자 발행)

> EVAL-ROUND-14 대응. 전 라운드 결정 유효.

## O1. 카카오 반자동 게시 담당·공수 확정 (01·05·06)

- **담당 확정**: 반자동 게시(백엔드 게시자산 준비 → 담당자가 채널 관리자 앱으로 게시)의 게시 주체 = **지사 담당자(자기 지사 채널) / 센터 운영자(센터 통합 채널·지사 부재 시 대행)**. 06 §A(역할)·§B(라우팅/역할 정의)에 정식 신설.
- **공수 계상**: 건별 게시 공수 **약 10분/건(가정 — 게시자산 다운로드·업로드·확인 포함, 실측 후 갱신)**. 01 §C-7 총부하표에 "카카오 채널 게시(건별 수작업)" 행 신설(주간 업로드 건수 램프 연동) → 4개 합계 행·상한 판단 재계산·인용처 전파. 05 §B-3은 01 §C-7 인용으로 정합(부하 반영 — 인건비 추가 채용은 아님, 기존 겸임 부하에 편입).

## O2. 정보통신망법 제50조 절 신설 (07, 06 연계)

- 07 §3에 **영리목적 광고성 정보 전송(정보통신망법 제50조)** 절 신설: ① 카톡 채널 메시지의 정보성/광고성 구분 기준 ② 광고성 발송 시 의무((광고) 표기·수신거부 수단·야간(21~08시) 전송 제한) ③ **채널 친구 추가가 수신 동의를 갈음하는지** 판정(카카오 비즈니스 약관 관행 + 한계) ④ **대리 등록(QR 부스·자녀 경유) 친구의 동의 유효성·증빙** 문제(01 §B-6 리스크와 연동) ⑤ 위반 제재(과태료). 기한 = **첫 채널 공지(대외 런칭) 발송 전**. 06 공지 운영 절차에 광고성/정보성 구분 확인 단계 1줄 연계.

## O3. 05 내부 파생표 정합 (05)

- §B-3③ "확장 미실현(2지사 고착)" 표의 보수 열 4셀을 라운드 13 정본값으로 교체(108→8 / 50→0 / 958~1,288→1,058.1~1,388.1 / 508~529→558.2~579.1 — 파이썬 재검산 후 기재). §G 대조 항목의 분모에 **05 내부 파생표**(본표에서 파생된 표들)를 편입("원천 변경 시 내부 파생표도 대조").
