## P1. `go.` 단축 링크 가용성 (02 소유, 04·08 단서 동기)

- **결정**: ① `go.` OG SSR 응답을 **Cloudflare 캐시(Cache Everything, 짧은 TTL + api 다운 시 stale 서빙)**에 얹는다 — 한 번이라도 캐시된 링크는 api 다운 중에도 미리보기·리다이렉트 생존. ② 편성표·고정 공지 등 **상시 노출 링크는 `watch.` 직접 링크를 병행**해 `go.` 의존을 줄인다. 담당: BE 리드, 기한: W1(go. 라우트 구축과 동시). 04·08의 "보강 후 VOD 신규 진입 생존" 셀에는 "`go.` 경유는 캐시된 링크 한정" 단서를 부기한다.

## P2. 현금 런웨이 트리거 (05 소유)

- 누적 상한(1.38억)과 별개로 **런웨이 트리거** 신설: 현재 현금 잔고 ÷ 최근 3개월 평균 순유출 = 잔여 개월. **<3개월 = 경보(조달원 실행 착수), <2개월 = 3단 의무 대응 즉시 발동**. 월례 점검 항목에 편입. 확장기 손익의 "4~6지사" 전제에 대해 **확장 미실현(2지사 고착) 시나리오**를 병기하고, 지사 확장의 실행 조건은 01이 소유(01에 신설)·05는 인용.

## P3. 서면 접수 채널 = 대표 이메일 1개 신설 (06 소유)

- 웹 "문의 폼"은 두지 않는다(익명 시청 모델·폼 스팸·대장 이원화 방지 — 근거 명시). 대신 **대표 이메일 1개**를 §A 채널 표에 신설: 용도 = 개인정보 삭제·법적 서면·광고주 문의 등 문서 접수가 필요한 건. SLA = 영업일 1일 내 접수 회신, 대장 기록 동일 적용. 웹앱 "문의하기"에 이메일 노출.
