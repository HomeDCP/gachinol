# 라운드 7 수정 — 문서 횡단 확정 결정 (조율자 발행)

> EVAL-ROUND-7 대응. X~T 결정 유효. 구조적 공백 3건(S1~S3)이 핵심.

## S1. 개발 인력 비용 = "자체 개발" 가정의 명시적 계상 (05 소유)

- 05 §B-3①에 **개발 인력 행** 신설: 현재 모델 = **자체 개발(창업자 직접 + AI 개발 도구)** — 현금 지출 0원이되 **"무급 자기노동" 가정임을 명시**하고 주당 투입 시간(가정)을 기재한다. **외주/채용 전환 규칙** 병기: 자체 개발 지속 불가 판단(트리거: W 단계 2개월 이상 지연 또는 창업자 가용 시간 상실) 시 시장가(월 400~600만원, '가정') 로 §B-3②·③ 전면 재계산. 전 문서 249회 역할 배정(BE·FE 리드 등)이 이 가정 위에 있음을 05가 명시한다.

## S2. 외부 법률자문 리테이너 = MVP 실비용 계상 (05·06)

- 05 §B-3①에 **법률자문 리테이너 행** 신설: 트리거성 증분이 아니라 **첫 촬영 재개 전 계약 필수 → MVP 상시 비용**(월 30~50만원 '가정', 06 §C 3선·07 §6 계약 요구의 재무 반영). §B-3③ 누적·상한 재계산에 포함.
- 06 §E에 **미계약 지속 시 종료·대체 규칙**: 계약 미체결 상태가 "첫 촬영 재개 예정일"에 도달하면 촬영 재개를 보류(게이트), 센터장 잠정 대행은 **"의심스러우면 임시 비공개" 기본값 + 대행 상한(법적 판단이 필요한 복원 결정은 대행 불가)**으로 한정.

## S3. 서비스워커 갱신·캐시 무효화 정책 (02 소유)

- 02 §D-T5(또는 신설 소절)에 명시: ① 정적 자산 = 콘텐츠 해시 파일명(캐시 버스팅) ② SW 갱신 = 신규 SW 감지 시 `skipWaiting`+`clients.claim` 즉시 활성 + 열린 탭 "새 버전" 토스트 ③ HTML 엔트리는 no-cache(항상 재검증) ④ 배포 파이프라인에 Cloudflare 캐시 퍼지 단계 ⑤ "웹 배포 즉시 반영" 주장(PIVOT-PLAN §1)의 기술 근거가 이 정책임을 명시. PWA·쉘 웹뷰 모두 동일 적용.

## S4. 01 정합 2건

- §B-2 부스 빈도(주 4.5회)와 §C-7 총부하(주 3h)의 모순은 **총부하표를 부스 실제 빈도 기준으로 재계산**하는 방향으로 정합(부스 축소가 필요하면 §B-2 목표를 하향하고 연쇄 갱신 — 01이 판단하되 양쪽이 같은 수치를 보게 하라). §C-7에 "간단 모드 사후 자막 입력"(지사 담당자 부하) 항목 신설. SSOT 요약의 M3~M5 상한 표기 정정.

## S5. 06 §C⑤ 오참조 분리

- 채팅 신고 중 **명예훼손 절차 근거 = 07 §5-1**(임시조치)로 정정(불법촬영물=§3-8 유지). 콘텐츠 본편의 명예훼손 삭제 요구는 §C① 계열(초상권·인격권)로 유형 표에 귀속 명시.

## S6. 신규 위임의 대장 등재 (조율자 수행)

- 04 §H 19·20번이 05에 위임한 2건(라이브커머스 회당 실측→05 반영, Tier-1 견적→05 비용 축)을 PIVOT-PLAN §6 대장에 행으로 추가한다(수정 라운드 종료 후 grep 검증과 함께).
