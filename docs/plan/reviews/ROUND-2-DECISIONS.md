# 라운드 2 수정 — 문서 횡단 확정 결정 (조율자 발행)

> EVAL-ROUND-2의 치명 이슈 3건(I-1~I-3)과 횡단 모순에 대한 **단일 결정**. 모든 수정 에이전트는 이 결정을 따른다.
> [ROUND-1-DECISIONS.md](ROUND-1-DECISIONS.md)의 X1~X9는 계속 유효하다.

## Y1. 범위 결정 — 실 STT·자동편집은 웹 피벗 범위 밖 (I-2·I-3 해소)

- **사실 확정(정직 기재 의무)**: 현재 리포에서 ① `auto_edit`(자동편집 마스터)는 **미구현**(로드맵 후보), ② ai-worker는 **결정적 스텁**(파이프라인 배선·`ai_analyses` 기록·추천 랭킹은 완료, 실 STT/비전 품질은 미주입), ③ 실 STT(RTZR)·실 비전 주입은 기존 로드맵 "다음 후보 3"이다. 계획 문서의 "자동편집·AI 분석 구현 완료·무변경" 계열 진술은 전부 이 사실로 정정한다.
- **범위 결정**: 웹 피벗(W0~W4)은 **배포 형태 전환**이다. 실 STT·비전 주입·자동편집은 **별도 트랙 T-AI**로 분리하고 W 게이트에 **비의존**시킨다(W 단계 완료 판정에 T-AI 불포함). T-AI는 08에 병렬 트랙으로 표기: T-AI-1 = RTZR STT + 비전 실 제공자 주입(기존 `/analyze` 계약 유지 — 어댑터 주입만이라 웹 피벗과 충돌 없음), T-AI-2 = `auto_edit` 자동편집(기존 로드맵 후보 2). 착수 순서는 W2 완료 후 우선 검토.
- **서비스 성립성 논증 수정**: 피벗 후에도 성립하는 루프는 "촬영→**자동 트랜스코딩·프리뷰**→기자 승인→송출→시청"(전 구간 구현·E2E 검증 완료)이며, "AI 편집"은 **현재 = 자동 처리 파이프라인, 향후 = T-AI로 고도화**로 정직하게 표현한다. 대외 마케팅 문구도 T-AI 전까지 "AI 자동편집" 단정 표현을 절제한다.
- **간단 모드·주민 임시 업로드 링크는 STT 비의존으로 재설계**: 자막·설명은 현행 Scene 구조대로 **사람(기자/검수자)이 입력**한다. STT 자동 자막은 T-AI-1 가동 후의 **개선**이지 전제가 아니다. 03 §C의 STT 전제 서술은 이에 맞게 수정.

## Y2. 디자인 토큰 승격의 수신처 확정 (I-1 해소)

- 03이 위임한 `packages/ui` 디자인 토큰 승격(rem/CSS 변수 경로 포함)을 **02 §B 수정 대상 + §E 체크리스트(W1 구간)**와 **08 W1 선행조건**에 정식 등재한다. 03은 구현 참조만 유지.

## Y3. 전화 CS 운영시간 모순 해소 (택일 결정)

- **결정: 코어타임 축소안 채택.** 전화 "즉시 응대"는 **평일 코어타임 주 25시간**(예: 10~12시·14~17시)으로 한정하고, 그 외 시간은 **당일(익영업일 오전 내) 콜백 + 카톡 유도 ARS 안내**로 변경한다. 05 §B-3 인건비(센터 운영 0.5인 ≈ 87h/월)와 정합.
- **MVP 예상 문의량 가정 신설**: 월 문의 60~120건(가정: 주간 활성 시청자 500~1,500명의 6~8%가 월 1회 문의 — 근거는 가정으로 명시). 이 가정 대비 월 300건 채용 트리거의 여유율도 함께 기재.

## Y4. 04의 08 트리거 인용 정정

- 08 §C에는 "월 4시간" 가용성 트리거가 존재하지 않는다(라운드 1에서 삭제됨). 04는 **실존 트리거만 인용**한다: 08 §C②(라이브 방송 중 제온 기인 장애 2회 / p95 24h 초과 주 3회) + 05 §C(전면 전환). 04 자체 트리거 신설 금지.

## Y5. 재사용률 재산정 (정직 하향)

- 02 §B의 "재사용 ≈93%"는 **신규 작성 파일(웹 업로더 어댑터·hls.js 어댑터·토큰 승격·주민 링크 화면 등)을 분모에 포함**해 재산정한다. 산정식(대상 파일 수·수정 파일 수·신규 파일 수)을 표로 명시하고 결과 수치를 정직하게 기재한다(수치가 80%대로 내려가도 그대로 쓴다 — 과대 주장이 감점 원천).

## Y6. 예산·인력의 단일 원천 = 05

- 03의 어르신 패널 예산(≈162~246만원), 01의 객원 인력 활동비, B2B 영업 인력 공수를 전부 **05 §B 예산·인건비 표에 편입**한다(05가 단일 원천, 01·03은 인용만). 객원 활동비 30만원에는 근거 확보 액션(시장가 조사, 담당·기한)을 부여한다.

## Y7. 수요 KPI 궤적의 단일 원천 = 01

- 01의 수요 KPI(주간 활성 시청자·완시청률 궤적)를 **04 §E(동시 시청자 단계·전환율)와 05(GMV 분해: 시청자×전환율×객단가)가 인용**한다. 두 문서의 예시 수치가 01 궤적과 어긋나면 01에 맞춰 수정한다. GMV 분해는 05가 자기 인용한 벤치마크(시청자당 1,550원)와 배수 대조를 명시한다.

## Y8. 주민 임시 업로드 링크의 API 실체 등재

- 주민 링크는 신규 API(발급·만료·건수/용량 제한·업로드 수신)가 필요하다 — 02 §B(api 추가 목록)와 §E(W2 항목)에 **엔드포인트 수준으로 등재**한다(설계 상세는 실행계획에서). 07 §3-15(무인증 업로드의 법적 통제 — 라운드 2에서 신설 예정)와 상호 참조한다.
