## D9-1. 앵커 ⑨ 형식 규칙의 외연·성격 정정 — S-11

**확정.** D6-4의 "원시 수치 주장 금지"는 **자체 점검 '인용 요약문' 절**(E1 §E·E1 §신규위임목록 상태 근거·
E4 §F·§F-1)에만 적용한다. **검산 절**(E2 §F·E3 §C 재검산 블록·E3 §G)은 성격이 다르다 — 명령+출력 전문을
담는 절이므로 수치 자체는 정당하며, 대신 "**재현 명령 동반 의무 + 앵커 ⑨ 재실행 대상**"으로 규정한다.
앵커 ⑨의 대상 절을 이 7개로 **명시 열거**하고, 형식 규칙 ①은 "인용 요약문 절에서의 원시 수치 주장 발견 시
위반 보고 / 검산 절에서는 출력 stale 발견 시 위반 보고"로 이원화한다(문면상 상시 위반 5건 무력화 해소).

## D9-2. 앵커 ⑫ 재정의·2식 폐기 — S-9·S-10

**확정.** 앵커 ⑫ = "**PIVOT §6 본문 총계 = 67(마스터플랜 계상 기준 — §6 본문 선언 고정 상수, 6-5 제외) +
§6-11 표 데이터 행 수(`grep -c '^| [0-9]+ |'` 계수)**" 1식만 유지. **2식(문서 측 `→ 6-11 #n 참조` 마커
대조)은 폐기** — 조율자 직접 등재행(#16~#21류)은 문서 측 마커가 원리적으로 없다. E5 §D 연장 운영 대상의
이중 표기는 "계상 기준 67행(§6 본문 총계 산식용, 6-5 제외) / 물리 행 73(6-5의 6행 포함) — 관계식에는 67
사용"으로 1문 정리.

## D9-3. 앵커 ④ 정밀화 — S-8

**확정.** 앵커 ④ = "E2 §E의 `T-NC-` 행 수 = **E3 §D의 `T-NC-` 접두 데이터 행 수**(`grep -cE '^\| T-NC-'`)
= E4 §A-3 건수 = E5 §C 하단 문구 건수". E3 §D 표의 비-T-NC 행(T-TRIG·앵커4 대외 런칭)은 계수 제외를 명시.

## D9-4. E5 §F 국면 구분 수신 + 분모 밖 위임 등재 — S-6

**확정 문안**(E5 §F 리스크1 비고): "**국면 구분** — 구현 진행 중 게이트② 대기 누적은 정상(슬롯 설계상
필연), **구현 태스크 전건 완료 후에도 대기 지속**이면 이상 신호로 트리거 판정(E4 §A-1 슬롯 개방 국면 인용)".
조율자가 이 위임쌍(E4 §A-7 → E5 §F)을 §6-11 #22로 등재(분모 밖 해소).
