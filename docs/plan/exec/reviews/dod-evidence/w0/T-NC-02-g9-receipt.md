## ① 도메인 — 임시 도메인으로 선행

**사용자 확인 내용**: 임시 도메인으로 W0~W2 기술 검증을 진행한다.

**근거·정합**: 08 §D 리스크 "도메인·브랜드 미결정으로 W0 지연"의 완화책 원문("임시 도메인으로 W0~W2 기술
검증 진행")과 동일하다. E3 §F ① 행의 우회 경로를 그대로 적용한다.

**실행 영향**: **T-NC-01**(외부 `https://api.<도메인>/health` 도달 실측)**만 보류**한다. 그 외 전 웨이브는
임시 도메인 또는 로컬 LAN으로 코드·통합 검증을 진행한다(E3 §F ① 우회 경로 열, EVAL-ROUND-18 V2-7 경계 기준).

**미결 잔여**: 확정 도메인 문자열 자체는 아직 없다. 확정 상신의 종점은 E5 §E "사용자 개입 필요 시점" 1번이며,
확정 시 본 파일에 행을 추가한다.

## ② 제온 노출 방식 — 미확정 (계획의 2안 밖 후보 제시됨)

**사용자 확인 내용**: 방식을 아직 정하지 않았다. **Tailscale**을 붙이는 안을 포함해 검토 중이며, 결정되면
추후 알려주겠다.

**⚠️ 계획과의 차이 — 조율자 주의 등재**: EXEC-PLAN G9 ②와 E3 §F ② 행, 08 §D는 선택지를
**Cloudflare Tunnel / 포트 개방 2안**으로만 규정하고, 08 §D는 "**W0 착수 + 4주 초과 시 승인 대기를 종료하고
Tunnel 단독안으로 자동 확정**"을 데드라인으로 둔다. **Tailscale은 그 2안 밖이다.**

→ 사용자가 실제로 Tailscale을 채택하면 **계획과 달라지는 결정**이므로 G7에 따라 `EXEC-DECISIONS.md`에
신규 `#n`으로 기록하고 08 §D·E2 T-W0-03 산출물란·E3 §F ② 행을 갱신해야 한다. **채택 전까지는 본 기록이
"2안 밖 후보가 검토 중"이라는 사실의 등재처다.**

**실행 영향**: T-W0-03의 **설정 코드 작성은 진행하고 실 연결만 보류**한다(E3 §F ② 우회 경로 열). 즉
Wave 2에서 T-W0-03을 정상 발주하되, `cloudflared` 서비스 블록/방화벽 허용 규칙 중 **어느 것도 실제 인프라에
적용하지 않는다**. 08 §D 4주 데드라인의 기산점은 W0 착수일(= Wave 1 착수, 2026-08-08)이므로 **2026-09-05**가
자동 확정 시점이다 — 그 전에 사용자 통보가 없으면 조율자가 Tunnel 단독안으로 자동 확정하고 본 파일에 기록한다.

## ②-확정 제온 노출 방식 = Cloudflare Tunnel (2026-08-09)

**사용자 확인 내용**: "제온 외부배선은 클라우드플레어 무료티어로 확정"(Claude Code 실행 세션, 직접 응답).

**판정**: 계획이 규정한 **2안 중 1안(Cloudflare Tunnel)**이다. 위 ②에 등재해 둔 **2안 밖 후보(Tailscale)는
채택되지 않았다** → G7 계획 이탈 기록 **불요**, 08 §D·E2 T-W0-03 산출물란·E3 §F ② 문안 개정 **불요**
(상태만 "미확정"→"확정"으로 갱신). 08 §D의 자동 확정 데드라인(2026-09-05)은 **발동 전에 사용자 통보가
도래**해 미발동으로 종료한다 — 결과가 같더라도 근거는 자동 확정이 아니라 **사용자 결정**이다.

**남은 제약(중요)**: G9 ①(도메인 문자열)은 여전히 미확정이다. Cloudflare **named tunnel**의 public
hostname은 Cloudflare zone(= 보유 도메인)을 요구하므로, 도메인 확보 전에는 **Quick Tunnel
(`*.trycloudflare.com` 임시 URL, 계정·도메인·지출 전부 불요)**로 운용한다. 08 §D 완화책 "임시 도메인으로
W0~W2 기술 검증 진행"의 범위 안이며, 도메인 확보 시 named tunnel + 서브도메인 5종 vhost로 승격한다
(T-W0-03의 nginx 골격이 이미 그 형태다). **Quick Tunnel의 URL은 재기동마다 바뀌므로 상시 운영에는
부적합**하다 — 대외 공개(앵커4) 전에 도메인이 필요하다.

**실행 영향**: T-W0-03의 "실 연결 보류"가 해제된다. 단 배포 실측 중
**제온의 nftables `forward` policy drop으로 Docker 컨테이너 아웃바운드가 전면 차단**돼 있음을 발견해
(EXEC-DECISIONS #22 ⑦), `cloudflared`는 compose 서비스가 아니라 **호스트 데몬으로 설치**한다.
그 판단의 근거·되돌리는 조건은 #22 ⑦이 원천이다.

## ③ 운전자금 — 미확인, 무지출 범위 선행

**사용자 확인 내용**: 05 §G MVP 착수 게이트(최소 3개월치 운전자금 — 기본 약 2,018~2,345만원 / 보수 약
2,057~2,383만원, 05 라운드18 재계산치)의 확보가 **확인되지 않았다**. 무지출 범위만 선행한다.

**근거·정합**: **EXEC-DECISIONS #8**(운전자금 게이트의 무지출 로컬 선행 해석)을 그대로 적용한다 —
① G9 원문 "기술 준비 작업은 로컬 검증 범위 내 선행 가능" ② 재무 게이트의 보호 목적은 현금 소진 방지이며
로컬 개발은 지출 0이라 무충돌.

**실행 영향**: 코드 웨이브는 진행하되 **실 배포·비용 발생 단계는 보류**한다. 재확인 경계는
**T-NC-20(Cloudflare Stream 실계정 개설 — 그 자격증명을 소비하는 코드 태스크는 T-W2-15, Wave 10) 착수 직전**이며
(E3 §F ③ 및 그 하단 "우회 경로의 한계"), 미확인 상태로 이 경계를 넘는 것은 E5 §A "테스트 미실행 완료 선언
금지"와 동급의 절차 위반으로 취급한다.

**부수 확인 필요(조율자 메모)**: 도메인 구매·스토어 개발자 계정 등 소액 상시비(05 §B-1 기준 연 32~47만원)도
지출이다. 임시 도메인 선행(①)은 이 지출을 발생시키지 않는 범위로 운용한다.
