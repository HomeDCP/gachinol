  Workbox·T-W1-11a Playwright·T-W3-01 web-push)는 해당 앱 `package.json`을 **파일 소유권 열에 명시**한다.

  E3 §B에 등재. 편성 규칙: "**신규 의존성 추가 태스크는 웨이브당 1건**"(같은 웨이브에 2건 이상 배치 금지 —
  lockfile 동시 갱신 충돌). 현행 Wave 8(T-W1-03+T-W1-04 동시)은 이 규칙 위반이므로 **1건을 타 웨이브로
  재배치**한다(E3 재량 — 웨이브 구성 변경 시 완료 보고에 명시, E4 재계산 후행).
- **회귀·검증 편입**: E5 §B 회귀 표에 "의존성 추가 태스크는 `pnpm install --frozen-lockfile` 성공을 게이트①
  로그에 포함" 1행. E1 §A QA 리드 행·E5 §A 게이트②의 재현 범위에 lockfile 정합 확인 1구 추가.
- 02 §B "신규 의존성 추가 시 이 표에 행 추가" 상시 의무의 수신: 해당 4개 태스크 산출물란에 "02 §B 표 행
  추가" 명시(E2).

## D6-2. 동적 라우트 신설 = SPA 폴백·모수 동반 원칙 — W-8 (EXEC-DECISIONS #6으로 기록)

**확정.** "**동적 라우트를 신설하는 태스크는 ① nginx SPA 폴백 패턴 추가(`infra/docker/nginx.conf` — 소유권
열에 명시, 준-공용 주의)와 ② 라우트 스모크 모수 편입(EXEC-DECISIONS #4)을 동반 산출물로 가진다**" —

재현 명령 인라인) 신설.
