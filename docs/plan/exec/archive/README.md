## 이 이동이 필요했던 이유

**헤더에 "동결"이라고 한 줄 적는 것으로는 부족했다.** 서브에이전트는 grep으로 파일을 찾지
헤더를 읽고 판단하지 않는다. 실제로 E1이 *"BE 리드 = `services/api`·`packages/shared` 소유"*라고
지정해 뒀는데 **BE 리드는 한 번도 기동하지 않았다** — 죽은 문서가 살아 있는 척한 결과다.

⇒ **경로에 `archive/`가 들어가야 죽은 것이 죽은 것으로 보인다.**
