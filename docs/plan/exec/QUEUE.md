# QUEUE — 개발순서계획도 (순서의 단일 원천)

> **역할 분담**: 순서는 여기. **범위·DoD는 E2**, **결함 진단은 대장(PIVOT-PLAN §6-*)**,
> **세션 인계는 HANDOFF**, **왜 정체됐는가는 ROOT-CAUSE-2026-08.md**.
>
> ## ⚠️ 이 문서의 절대 규칙 — 가변 값을 적지 않는다
> 완료 여부·파일 수·계수·커밋 해시·테스트 수를 **여기 적지 않는다.** 적는 순간 썩기 시작한다.
> 필요하면 **재현 명령만** 적는다. 이 리포의 계획 문서가 전부 stale해진 원인이 값 박제였다
> (ROADMAP은 89행짜리 얇은 문서인데도 죽었다 — **얇음은 stale의 예방이 아니다**).
>
> **갱신 시점**: 슬라이스 종료 시. 커밋마다·매일이 아니다.
> **갱신 소유자**: `scribe`. 조율자가 직접 고치지 않는다(규율 8이 4회 깨진 자리가 여기다).
