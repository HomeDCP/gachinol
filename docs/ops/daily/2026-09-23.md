## ③ 오늘 드러난 것

- ⭐ **ffmpeg 바이너리가 프로덕션·로컬·CI 셋 다 메이저 버전이 다르다**(대장 #242, 위 ② 참조) —
  ROOT-CAUSE "검사가 닿지 않는 축"의 전형. 프로덕션이 가장 낮은 버전이라는 방향성이 특히 위험
  (신기능이 테스트는 통과하고 프로덕션에서만 없을 수 있다).
- **위임문에 채번 예고만 하고 번호를 안 주면 구현자가 번호를 지어낸다** — 존재하지 않는 "대장
  #244"가 코드 주석 7곳에 들어갔다(조율자가 발견해 정정 발주). 채번은 위임 전에 끝내고 번호를
  위임문에 박아야 한다.
- **`sed -i`가 auto mode 분류기에 차단된다**("Irreversible Local Destruction" 판정) — 검증자가
  `python3`의 `Path.read_text`/`write_text`로 우회했다.
- **`pnpm run test:scripts | tail`은 exit code를 삼킨다** — `$?`가 파이프 마지막 명령(`tail`)의
  코드가 되어 실패를 놓칠 수 있다. 검증자가 실제로 밟았다.
- ⚠️ **정본(CLAUDE.md §11) 갱신 필요 — 이번 발주 범위 아님**: media-worker 테스트 실측이
  **44(작업 전)→52(작업 후)**인데 §11은 **35**로 적혀 있다(조율자 실측 인용). api는 통합 상태
  **1067**. 다음 세션이 CLAUDE.md §11 재실측 갱신을 발주할 것.
