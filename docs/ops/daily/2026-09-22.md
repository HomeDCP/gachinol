## ③ 오늘 드러난 것

- **`git checkout -- <path>` 사고** — 위임문이 뮤테이션 원복 명령으로 그것을 지시했고, 검증자가
  그대로 실행해 구현자의 미커밋 변경분이 소실됐다(원인은 검증자가 아니라 위임문). 검증자가 세션
  내 Read 원문으로 즉시 재구성했고, 조율자가 git blob 해시 대조로 바이트 동일을 확인했다. 상세는
  `docs/plan/exec/HANDOFF.md` "함정 2026-09-22" 절 항목 1(조율자 실측 인용).
- **`verifier.md`에 git 쓰기 금지 목록이 없었다** — scribe가 이전 세션에서 발견해 오늘 조율자가
  직접 대조 확인(`grep -n "checkout" .claude/agents/implementer.md` → 13행에 전부 금지 명시 /
  `grep -c "checkout" .claude/agents/verifier.md` → **0**, 대조 전). 오늘 보강 완료(위 ②,
  `.claude/agents/verifier.md` 13-15행·28-38행).
- **CLAUDE.md §11의 api 테스트 기록치 `901`이 stale이다**(실측 1050→1060, 조율자 실측 인용 —
  scribe는 `services/**` 실행 없이 독자 재현 못함). ⚠️ **정본(CLAUDE.md) 수정은 이번 작업
